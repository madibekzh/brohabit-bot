# 🎯 Мақсатқа жақындататын әдеттер трекері (Telegram Bot)

Бұл Telegram бот сізді үлкен мақсаттарыңызға жақындататын күнделікті әдеттерді қалыптастыруға, оларды уақытында еске салып тұруға және үздіксіз серияңызды (🔥 **Streak**) сақтауға арналған.

---

## 🌟 Негізгі мүмкіндіктері

1. **Әдеттер мен Мақсаттар байланысы**:
   - Бот ең алдымен сізден қандай әдет қалыптастырғыңыз келетінін сұрайды.
   - Әрбір әдетті белгілі бір үлкен мақсатпен байланыстырады (мысалы: *«Күнде 20 бет кітап оқу»* ➔ *«Жылына 20 кітап бітіру»*).
2. **Күнделікті Еске салулар (Smart Reminders)**:
   - 🌅 **Таңертеңгі еске салу** (әдепкі: 09:00) — күнді мақсаттармен жоспарлау.
   - ⏰ **Жеке әдет еске салуы** — әр әдетке өзіне ыңғайлы уақытты белгілеу (мысалы: 20:00).
   - 🌙 **Кешкі қорытынды** (әдепкі: 21:00) — орындалғандарын белгілеп, күнді түйіндеу.
3. **🔥 Үздіксіздік сериясы (Streak) & Прогресс**:
   - Әдетті күн сайын орындаған сайын серия артады (`🔥 1 күн`, `🔥 2 күн`...).
   - Нақты прогресс-бар: `[▓▓▓▓▓▓░░░░] 60%`.
4. **Интерактивті батырмалар**:
   - Бір басу арқылы ✅ Орындалды / ⭕️ Болдырмау.
   - Еске салу хабарламасы келгенде бірден [✅ Орындадым!] батырмасын басу.
5. **Жігерлендіру (Мотивация)**:
   - Әрбір жеңіс сайын шабыттандыратын нақыл сөздер мен қанатты сөздер.

## 🚀 Іске қосу нұсқаулығы

### 1-қадам: Telegram-нан бот токенін алу
1. Telegram-нан [@BotFather](https://t.me/BotFather) іздеп, ашыңыз.
2. `/newbot` командасын жіберіңіз.
3. Ботыңызға ат беріңіз (мысалы: `MyGoalTrackerBot`).
4. `@BotFather` сізге арнайы **API Token** береді (мысалы: `7123456789:AAFx...`).

### 2-қадам: `.env` файлын толтыру
Осы бумадағы `.env` файлын ашып (немесе `.env.example` үлгісімен), токеніңізді жазыңыз:

```env
BOT_TOKEN=сіздің_телеграм_токеніңіз_осында
DEFAULT_TIMEZONE=Asia/Almaty
```

### 3-қадам: Ботты іске қосу
Терминалда мына пәрмендерді орындаңыз:

```bash
# 1. Виртуалды ортаны іске қосу
source .venv/bin/activate

# 2. Ботты жүргізу
python bot.py
```

## 📱 Бот командалары мен мәзірі

- `/start` — Ботты бастау (бірден жаңа әдет қалыптастыруды ұсынады)
- `/habits` — Бүгінгі әдеттерді көру және белгілеу
- `/add` — Жаңа әдет қосу
- `/stats` — Статистика, рекордтар және серия (Streak)
- `/settings` — Еске салу уақыттарын өзгерту
- `/help` — Көмек және нұсқаулық
- `/cancel` — Кез келген енгізу процесінен бас тарту

## 🛠 Технологиялық құрылым
- **Python 3.9+**
- **aiogram 3.x** — Заманауи асинхронды Telegram Bot фреймворкі
- **aiosqlite** — Жылдам әрі сенімді асинхронды SQLite деректер қоры
- **APScheduler** — Минуттық дәлдікпен жұмыс істейтін еске салу жүйесі
